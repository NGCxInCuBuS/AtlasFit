# AtlasFit 💪
Personal offline Android workout tracker. Four-day athletic-muscular training plan, editable weights/sets/reps, exercise completion, workout history, body weight and waist logs, and backup/restore.

## Build the APK
Open the repository's **Actions** tab → **Build AtlasFit APK** → **Run workflow**, or wait for the automatic push build. When the build succeeds, open the run and download the **AtlasFit-debug-APK** artifact. Extract the ZIP and install app-debug.apk on Android.

The debug APK is signed by the Android debug key for personal testing. Keep your phone's workout data backed up before uninstalling; data is stored locally on your device.

## Notes
Machine weight values are personal starting references, not prescriptions. The app works offline.
